# GSNW

GSNW 是一个用 Go 语言编写的轻量级终端复用器，类似于 tmux/screen。它允许你创建和管理多个持久化的终端会话，支持多窗口和多客户端连接。

## 特性

- **会话持久化**: 会话在客户端断开后仍然保持运行
- **多窗口支持**: 每个会话可以包含多个终端窗口
- **多客户端连接**: 多个客户端可以同时连接到同一个会话
- **自动终端调整**: 支持终端窗口大小自动同步
- **轻量高效**: 使用 Unix 域套接字进行客户端-服务器通信

## 安装

### 从源码构建

```bash
# 克隆仓库
git clone https://github.com/your-username/gsnw.git
cd gsnw

# 构建
go build -o gsnw cmd/gsnw/main.go

# 或者使用提供的构建脚本（构建 Linux x86-64 版本）
./build.sh
```

### 依赖

- Go 1.21+
- `github.com/creack/pty` - PTY 支持
- `github.com/spf13/cobra` - CLI 框架
- `golang.org/x/term` - 终端处理

## 使用方法

### 基本命令

```bash
# 启动或附加到默认会话
gsnw

# 创建新的命名会话
gsnw new -s mysession

# 附加到指定会话
gsnw attach -t mysession

# 列出所有会话
gsnw list
gsnw ls

# 终止会话
gsnw kill -t mysession
```

### 快捷键

GSNW 使用 `Ctrl+B` 作为前缀键（类似 tmux）：

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+B c` | 创建新窗口 |
| `Ctrl+B n` | 切换到下一个窗口 |
| `Ctrl+B p` | 切换到上一个窗口 |
| `Ctrl+B 0-9` | 切换到指定编号的窗口 |
| `Ctrl+B d` | 分离当前会话 |
| `Ctrl+B &` | 关闭当前窗口 |
| `Ctrl+B Ctrl+B` | 发送 Ctrl+B 到终端 |

## 工作原理

1. 客户端启动时检查服务器是否运行，如未运行则在后台启动
2. 服务器在 Unix 域套接字上监听连接 (`/tmp/gsnw-[uid]/default.sock`)
3. 客户端连接后进入 raw 终端模式
4. 用户输入通过二进制协议发送到服务器
5. 服务器将输入路由到活动窗口的 shell
6. shell 输出广播给所有连接的客户端
7. 用户可以分离会话，会话继续在后台运行
8. 重新附加时可以恢复会话

## 协议

GSNW 使用自定义二进制协议进行通信：

- **消息头**: 1 字节消息类型 + 4 字节负载长度（大端序）
- **负载**: 可变长度数据（最大 1MB）
- **消息类型**: 新建会话、附加、分离、列表、终止、输入、输出、窗口操作等
